# 📚 BookBadli

**BookBadli** is a community-driven platform that allows users to connect with book lovers, browse books, exchange books without money, and build their personal libraries.  
It is designed to make book sharing easy, safe, and social.

## 🚀 Features

- **User Authentication:** Secure sign-up, login, and profile management.
- **Browse Books:** Search and filter available books.
- **Nearby Books:** View books available near your location.
- **Add Books:** Upload and share your own books.
- **Exchanges:** Request, accept, and track book exchanges.
- **User Dashboard:** View your books, exchanges, and profile details.
- **Notifications:** Alerts for exchange requests and updates.
- **Responsive Design:** Works on desktop and mobile devices.
- **Secure Authentication:** JWT-based authentication and authorization.

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Shadcn UI
- React Router
- Redux Toolkit
- Lucide Icons

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT (JSON Web Tokens)
